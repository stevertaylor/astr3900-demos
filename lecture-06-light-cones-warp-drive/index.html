The metric (Alcubierre 1994)

ds² = −dt² + [dx − Vs(t) f(rs) dt]² + dy² + dz²
dx / dt = ±1 + Vs(t) f(rs) null directions (ds = 0) — this is exactly the tilt field drawn on the diagram
Vs(t) ≡ dxs / dt    rs² ≡ (x−xs(t))² + y² + z²

Cartesian ↔ polar coordinates

Drag P to move it; drag Q to change the small step from P to Q.

dx,  dy
dr,  r dφ  (r at P)
dx2 + dy2
dr2 + r2dφ2
difference
ds2 = dx2 + dy2 = dr2 + r2dφ2

The two agree exactly only as Q → P: the line element is a statement about infinitesimal steps. Pull Q in and watch the difference vanish faster than ds2 itself.

The coordinates change; the Euclidean geometry and line element do not.

Moving light clock

c = 1, mirror separation L = 1. S is the clock's rest frame; in S′ the clock moves along x′. L is transverse to the motion, so it is unchanged.

Δt = 2L/c  (one tick, in S)
γ = 1/√(1−β2)
Δt′ = 2γL/c  (same tick, in S′)
Δx′ = vΔt′
−(cΔt′)2 + (Δx′)2
cΔt′/2 = √[L2 + (Δx′/2)2]

For events A and C the interval is Δs2 = −4L2 in every frame.

The lower-left plot is only the x′–ct′ projection. The photon also moves in y′, so its projected path there must not be read as a 45° null ray.

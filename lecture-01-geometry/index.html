Universal free fall · coordinate descriptions · light-clock invariance
Change the test mass

Mass: 1.0 arbitrary units

The body gets bigger. The curve does not move.

For the same initial position and velocity, and neglecting non-gravitational forces such as air resistance, freely falling test bodies have the same acceleration.

h(t) = h₀ + v₀t − ½gt²
dh/dt = velocity,   d²h/dt² = −g

The plotted curve is a complete constant-acceleration trajectory: h(t) is quadratic, so it is a parabola.

Time runs up the page and height runs across it, following the lecture notes. Read this way the parabola is already a worldline, which is the object panel 3 returns to.

Cartesian ↔ polar coordinates

At fixed r = 1, angle φ: 35°

Toggle the coordinate grid:

ds² = dx² + dy² = dr² + r²dφ²
x = r cosφ,   y = r sinφ

The slider reports φ in degrees for convenience; the differential dφ in the line element is understood in radians.

The coordinates change; the Euclidean geometry and line element do not.

Moving light clock

β = v/c: 0.60

Use c = 1 and mirror separation L = 1. Frame S is the clock rest frame; S′ sees the clock moving along x′. Because L is transverse to the motion, the mirror separation is unchanged.

Δt = 2L/c = 2.000
cΔt′/2 = √[L² + (Δx′/2)²]
γ = 1/√(1−β²),   Δt′ = 2γL/c = 2.500
Δx′ = vΔt′ = 1.500
−(cΔt′)² + (Δx′)² = −4.000

For events A and C, the spacetime interval remains Δs² = −4L².

The right-hand spacetime plot is only the x′-ct′ projection. The photon also moves in y′, so its projected path there should not be mistaken for a 45° null ray.
